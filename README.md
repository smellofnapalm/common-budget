 # Common Budget

Common Budget — веб-приложение для ведения общего бюджета двух человек. Поддерживаются общие траты (50/50), а также покупка товаров для другого человека или для себя. Проект состоит из серверной части, клиентского интерфейса и базы данных, которые запускаются совместно с помощью Docker.

## Бэкенд

Бэкенд отвечает за обработку запросов от фронтенда и взаимодействие с базой данных. SQL-запросы выполняются напрямую напрямую, без оберток типа SQLAlchemy или ORM. Для унификации обработки запросов используется собственный декоратор. Это велосипед, сделанный для того, чтобы потренироваться в написании SQL-запросов и доступе к БД.

Логика разделена по отдельным файлам:

- обработка GET-запросов для получения данных (`get_info.py`);
- обработка POST-запросов для добавления и изменения данных (`post_info.py`);
- инициализация базы данных и создание необходимых таблиц (`initialize_tables.py`);
- удаление таблиц и очистка структуры базы данных (`drop_info.py`).

Такое разделение упрощает поддержку проекта и позволяет независимо изменять отдельные операции с данными.

## Фронтенд

Фронтенд содержит базовую одностраничную HTML-страницу (`templates/index.html`). JavaScript отвечает за динамическое изменение содержимого страницы, отправку запросов на сервер и отображение полученных данных пользователю.

Клиентская часть не требует перезагрузки страницы при выполнении основных операций: данные можно получать и обновлять через запросы к API бэкенда.

## Запуск проекта

Для запуска сервера необходим установленный Docker с поддержкой Docker Compose.

1. Создайте файла `.env`
2. Откройте терминал в корне проекта.
3. Выполните команду:

```bash
docker compose up -d --build
```

Флаг `--build` пересобирает образы перед запуском и гарантирует, что используются актуальные изменения проекта. После запуска приложение будет доступно по адресу, указанному в конфигурации Docker Compose.

При необходимости остановить сервер можно выполнить:

```bash
docker compose down
```

## Конфигурация `.env`

Перед запуском создайте файл `.env` в корне проекта, рядом с `docker-compose.yml`. В нём задаются значения переменных, используемых Docker Compose и бэкендом:

```env
DB_HOST=localhost
DB_USER=YOUR_POSTGRESQL_USER_NAME
DB_PASSWORD=YOUR_POSTGRESQL_PASSWORD
DB_PORT=5432
DB_NAME=common_budget_db
```

Замените значения на свои. Названия переменных должны совпадать с переменными, указанными в `docker-compose.yml` и конфигурации сервера. После изменения `.env` пересоздайте контейнеры:

```bash
docker compose down
docker compose up -d --build
```
